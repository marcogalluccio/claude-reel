Monta i tuoi reel verticali
parlando con Claude.

Registri col telefono, e un agente costruisce sopra grafiche animate a tempo con quello che dici: sottotitoli karaoke, camera move, musica ed effetti sonori. Questa guida ti dice cosa ti serve e come si parte.

Come funziona, in tre passaggi
1

Giri col telefono

Un talking-head verticale, come faresti per un reel qualsiasi.

2

Dici cosa vuoi a Claude

Claude Code monta: taglia, ricuce l'audio, costruisce le grafiche sopra.

3

Rivedi a blocchi

Ogni pezzo si vede in anteprima prima del successivo: zero sorprese al render finale.

Cosa ti serve — richiesto

  • Claude Code
    da terminale, guida tutto il montaggio
  • Node.js + HyperFrames CLI
    il motore che renderizza le grafiche animate
  • FFmpeg
    taglia, compone, incolla i sottotitoli
  • Playwright
    controlla le grafiche prima del render vero

Opzionale — livello audio

  • ElevenLabs
    voce e trascrizione per i sottotitoli karaoke (piano gratuito disponibile)
  • HeyGen
    musica ed effetti sonori a libreria. Senza, il reel funziona lo stesso

Il prompt di setup

Apri Claude Code in una cartella vuota e incolla questo. Controlla cosa hai gia installato e installa il resto, chiedendoti conferma prima di toccare qualunque cosa di globale sul tuo Mac.

Set up https://github.com/marcogalluccio/claude-reel for me: it's a skill for
montaging vertical 9:16 talking-head reels with an animated graphics layer.

Read SKILL.md first. It needs Claude Code (already running), Node.js + the
HyperFrames CLI (pinned version, install with npx), ffmpeg, and Playwright for
QA screenshots before rendering. Check what's already installed on this
machine and install what's missing, asking me before anything system-wide.

The audio layer (voiceover transcription via ElevenLabs, music/SFX via
HeyGen) is optional: ask me to paste API keys only if I want that layer, and
skip it entirely if I don't.

Once everything is ready, tell me and wait: I'll drop a talking-head clip
into a folder and tell you what I want on top.

Cosa aspettarti dal primo montaggio

Non e un editor con dei bottoni: e una conversazione. Alcune cose utili da sapere prima di iniziare.

Si costruisce a blocchi, non tutto insieme

Prima la base tagliata e con l'audio pulito, poi la trascrizione, poi le grafiche, poi il composito, poi i sottotitoli. Ad ogni blocco ricevi un'anteprima prima che si passi al successivo — se qualcosa non ti convince lo dici li, non alla fine.

Lo stile e un punto di partenza, non un vincolo

La skill arriva con una palette e un set di grafiche gia pronte (card, sottotitoli karaoke, camera move). Puoi cambiare colori, font e come entrano gli elementi: e la tua skill di stile, dal secondo reel riparti dalle tue scelte.

Gli errori piu comuni (te li dice anche la skill)

  • Rendere le grafiche in un formato che perde la trasparenza: la skill sa qual e la via giusta su una macchina Mac tipica.
  • Muovere l'inquadratura (camera move) direttamente sul file originale invece che solo in fase di composizione: il girato originale resta sempre intatto.
  • Costruire una sola direzione grafica e scoprire dopo il render che non convince: la skill chiede sempre 2-3 alternative sui momenti chiave, prima di costruire.
